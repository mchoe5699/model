# QWERTY's Model

실제 기기를 마인크래프트 블록으로 옮기는 모드입니다. (Minecraft 1.20.1 / Forge 47.x)

![미리보기 (왼쪽: 새것, 호출 중 / 오른쪽: 철거품)](docs_preview.png)

## 수록 모델

### HT-100 도어카메라 / HT-100 도어카메라 (철거품)
아파트 세대 현관 옆에 붙는 도어카메라(초인종 겸 카메라)입니다.

- **설치**: 벽 옆면에 붙여 설치합니다. 붙어 있던 벽이 사라지면 아이템으로 떨어집니다.
- **실제 크기**: 세로 0.2블록(3.2px), 가로 약 0.15블록(2.45px), 두께 약 0.85px. 벽면 가운데에 붙습니다.
- **3D 모델 (OBJ)**: 사진을 기준으로 치수를 잡은 실제 입체 메시입니다.
  - 벽에 붙는 직선형 베이스 트레이와, 그 안에 끼워진 앞 커버(모서리를 크게 둥글린 곡면 테두리)
  - 위는 거의 평평하고 아래로 갈수록 튀어나오는 쐐기형 카메라 후드(아래 모서리 큰 곡률)
  - 후드에 파인 카메라 창 → 회색 프레임 → 한 단 더 들어간 유리, 유리 아래 적외선 LED 4개
  - 금속 렌즈 베젤, 검은 경통 단차, 코팅 반사가 보이는 돔형 렌즈
  - 실제로 파인 스피커 슬롯 6줄과 마이크 구멍 2개
  - 홈(포켓) 안에 들어앉은 둥근 사각 호출 버튼과 파인 LED 도광창
  - 베이스 양옆의 걸쇠 홈과 그 안에 보이는 커버 클립
  - 앞면에서 바닥 쪽으로 감싸는 하단 걸쇠
  - 기울어진 후드 면을 따라 붙은 로고·모델명 인쇄
  - 텍스처에 구워 넣은 그림자: 후드 아래 그림자, 구멍 둘레 음영, 모서리 굴림 음영
- **철거품**: 누렇게 바랜 플라스틱, 창 아래 테이프 자국, 검은 긁힘, 벽 페인트 자국, 들뜬 보호필름, 옆면 종이 라벨, 버튼 손때
- **호출 버튼**: 오른쪽 아래 사각 버튼을 우클릭하면 "띵동" 차임이 울리고 버튼 LED가 켜집니다. 약 1.6초 동안 레드스톤 신호 15를 냅니다(붙은 벽 블록에도 강한 신호). 레드스톤으로 문, 램프, 다른 모드의 장치와 연결할 수 있습니다.
- **야간 적외선 LED**: 앞면을 웅크리고 우클릭하면 켜고 끕니다. 켜지면 창 윗부분이 붉게 빛나고 약한 빛(3)을 냅니다.
- **철거품 버전**: 누렇게 바랜 본체, 들뜬 보호필름, 브래킷의 페인트 자국까지 표현했습니다.

### 조합법
- 도어카메라: 흰색 테라코타 6 + 색유리 1 + 레드스톤 1 + 돌 버튼 1 (C G C / C R C / C B C)
- 철거품: 도어카메라 + 흙 (무형 조합)

## 빌드
`main`에 푸시하면 GitHub Actions가 jar를 빌드합니다. **Actions → 최신 실행 → Artifacts → `qwertys_model-jar`** 에서 받으세요.

로컬에서 빌드하려면 JDK 17과 Gradle 8.1.1로 `gradle build` 를 실행하면 `build/libs/` 에 jar가 생깁니다.

## 텍스처·모델 다시 만들기
`python3 tools/gen_assets.py` 를 실행하면 OBJ 메시, 텍스처, 블록 모델, 블록스테이트, 아이템 모델이 다시 생성됩니다(Pillow 필요). 부품 치수는 스크립트 상단에서 바꿀 수 있고, `python3 tools/preview.py ht100_door_camera 결과.png` 로 게임 없이 여러 각도 미리보기를 렌더링할 수 있습니다(numpy 필요).
